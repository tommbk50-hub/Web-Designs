The hero gradient is rendered with Hazeglow. After editing `hero-gradient.jsx`, run `npm install` and `npm run build` to update the bundled `vendor/hero-gradient.js` used by the static page.
The hero also has a CSS gradient fallback in `index.html` for browsers where WebGL2 is unavailable.
