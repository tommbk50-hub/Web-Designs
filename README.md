Hazeglow renders behind the full page and responds to pointer movement while scrolling. The hero has a dark shade for white text; the rest of the page uses a translucent light surface for dark text. After editing `hero-gradient.jsx`, run `npm install` and `npm run build` to update the bundled `vendor/hero-gradient.js` used by the static page.
The page also has a CSS gradient fallback in `index.html` for browsers where WebGL2 is unavailable.
